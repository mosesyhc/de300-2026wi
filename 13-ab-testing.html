A/B Testing: Design and analysis

Experimental Design for Data-Driven Decisions

  • Goal: measure causal impact
  • Widely used in:
    • Product analytics
    • Marketing
    • Online platforms
  • Core idea:
    • Randomly split users into A (control) and B (treatment)

Example Scenario

Suppose we want to test:

Does a new signup page increase conversions?

Metric:

  • conversion rate

A/B Testing Pipeline

  1. Define metric
  2. Randomize users
  3. Run experiment
  4. Measure outcomes
  5. Statistical test
  6. Decision

Hypothesis Testing

\(p_A:\) conversion rate for A

\(p_B:\) conversion rate for B

\[H_0: p_A = p_B \quad \text{v.s.} \quad H_1: p_A \neq p_B.\]

Example metric:

Conversion Rate = conversions / users

Treatment effect:

\(\Delta = p_B − p_A\)

Two-Proportion Test

import numpy as np 
import matplotlib.pyplot as plt
from statsmodels.stats.proportion import proportions_ztest

np.random.seed(0)

n = 1000 
pA = 0.10 
pB = 0.12

A = np.random.binomial(1, pA, n) 
B = np.random.binomial(1, pB, n)

success = [B.sum(), A.sum()] 
nobs = [len(B), len(A)]

proportions_ztest(success, nobs)
(np.float64(2.2988195728615644), np.float64(0.021515186901800022))

If \(p < \alpha\), we reject the null hypothesis (for example, \(\alpha = 0.05\)).

import statsmodels.api as sm

ci_low, ci_high = sm.stats.proportion_confint(B.sum(), len(B))
ci_low, ci_high
(0.12036604574105579, 0.16363395425894417)

Interpretation:

Range of plausible values.

Simulating an Experiment

pA_hat, pB_hat = A.mean(), B.mean()

# Visualizing Conversion Rates

rates = [pA_hat, pB_hat]
sds = [np.sqrt(pA_hat*(1-pA_hat)/n), np.sqrt(pB_hat*(1-pB_hat)/n)]

plt.figure()
plt.errorbar(["A", "B"], rates, fmt='o', yerr=sds, linestyle='dashed', capsize=4)
plt.ylabel("Conversion Rate")
plt.title("Simulated A/B Test")
plt.tight_layout()
plt.show()

Statistical Power

How good are we in detecting a difference? \(\mathrm{Pr}\{\text{reject}\mid \Delta > 0\}\)

Depends on:

  • sample size
  • effect size
  • variance
  • significance level

For example, with \(n=1000\), this is how often we actually detect a difference:

n = 1000
means = []
effects = [] 
for _ in range(5000): 
    A = np.random.binomial(1, 0.1, n) 
    B = np.random.binomial(1, 0.12, n)
    stat, p = proportions_ztest([A.sum(), B.sum()], [n, n])
    means.append([A.mean(), B.mean()])
    effects.append(p < 0.05)

means = np.array(means)
np.mean(effects)

plt.figure()
plt.hist(means, density=True, bins=30, histtype='stepfilled', alpha=0.5)
plt.legend(["B", "A"])

Multiple metrics problem (Multiple testing)

Real experiments track:

  • conversion
  • engagement
  • retention
  • revenue

Or, the experiments test more than two groups at a time.

Testing many metrics increases false positives.

Common remedies

  • Bonferroni correction, \(\frac{\alpha}{m}\): controls Family-wise error rate: makes the chance of any false positive small.
  • Benjamani-Hochberg (BH), \(\frac{i \alpha}{m}\): controls False discovery rate: out of the “significant” results, keep the expected proportion of false positives small.

Key Takeaways

  • A/B testing estimates causal effects (by randomization)
  • Randomization removes bias
  • Hypothesis tests quantify uncertainty
  • Multiple testing must be controlled
